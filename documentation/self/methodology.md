# Methodology

Note: this methodology was created when I started looking at the problem.

1. First data inspection: both the case but especially the annual report.
2. Write initial notes (no AI), done [here](/documentation/self/notes.md)
3. Research on the topics of the risks (ie, a little bit of domain knowledge).
4. Write the specs in the initial notes
5. Have Claude review my initial notes
6. Write the first version of PLAN.md, manually.
7. Iterate the PLAN.md in Claude Code, recursively.
8. Same as 6 and 7, but for the DESIGN.md
9. First implementation.
10. First tests. Iterate. Improve.
11. Create STRETCH.md
